# Планер — Умное расписание дня (PWA)

Новое прогрессивное веб-приложение (PWA) на основе проекта «Ежедневник» с тайм-блоками, авто-сдвигом задач, паузой и звуковым будильником.

## Ключевые возможности:
1. **Тайм-блоки для задач**: Каждая задача имеет точное время начала и конца (например, `08:00 – 12:00`, `12:30 – 14:30`) с расчетом длительности.
2. **Ежедневный повтор и сброс**: Задачи повторяются каждый день в заданное время. При выполнении задачи за день она попадает в выполненные, а на следующий день готова заново.
3. **Умный авто-сдвиг задач («Проспал / перенос»)**:
   - Если вы меняете время задачи на сегодня (например, с `08:00–12:00` на `10:00–14:00`, разница +2 часа), все последующие задачи дня автоматически сдвигаются на те же 2 часа!
4. **Пауза и продолжение с авто-сдвигом**:
   - Во время выполнения задачи можно нажать «Пауза».
   - При нажатии «Продолжить» время окончания текущей задачи продлевается на время паузы, а все следующие задачи дня автоматически сдвигаются вперед на это же время.
5. **Звуковой будильник и уведомление**:
   - По окончании запланированного времени срабатывает звуковой сигнал (гармоничный колокольчик через Web Audio API) и появляется модальное окно с вариантами: «Отметить выполненной», «+15 минут со сдвигом», «+30 минут со сдвигом».
6. **Выбор области изменений**:
   - Можно изменить время «Только для сегодняшнего дня» (разовый перенос).
   - Либо «Для всех последующих дней» (обновляет базовый шаблон на будущее, не ломая прошлую историю).
7. **0 начальных задач**: Приложение запускается абсолютно чистым без демо-задач для комфортного тестирования.

## Запуск для разработки и тестирования:
```bash
npm run dev
```
или для запуска собранной версии:
```bash
npm run preview
```
